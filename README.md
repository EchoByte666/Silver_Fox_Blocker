## 项目简介

"银狐"（Silver Fox）木马是国内近年活跃的投毒团伙，通过伪装成正常软件（远控工具、破解补丁、安全软件官网）诱导用户下载运行木马。本扩展通过四层防护架构对网页进行多维度检测与拦截，专门针对银狐木马的传播链路（假官网 / 投毒论坛 / AI 生成钓鱼链接）设计。

## 架构

```
┌─────────────────────────────────────────────────────────────┐
│                    四层防护（缺一不可）                       │
├──────────┬──────────────────────────────────────────────────┤
│ 第一层    │ DNR 重定向：main_frame 导航层直接重定向到警告页    │
│ 第二层    │ webNavigation.onBeforeNavigate 导航兜底拦截       │

│ 第四层    │ 页面评分引擎：30 项风险指标加权评分               │
└──────────┴──────────────────────────────────────────────────┘
```

## 功能

### 拦截检测

| 层级 | 条件 | 行为 |
|------|------|------|
| 🔴 硬拦截 | 总分 ≥150 且证据类别 ≥2，或黑名单/强特征命中 | 跳转警告页（展示评分明细 + 正版官网引导） |
| 🟡 软拦截 | 总分 100–149 且含结构/资源类证据 | 警示横幅 + 页面冻结（可解冻） |
| 🔵 低权提示 | 总分 80–99 | 灰蓝细横幅（浏览不中断） |
| ⚪ 提示卡片 | 总分 60–79 或品牌冒充嫌疑 | 右下角悬浮卡片 |

### 平台智能豁免

针对不同类型网站的内容特征，自动切换检测策略：

| 平台类型 | 豁免 | 外链核查 | 示例 |
|----------|------|----------|------|
| **AI 对话**（28 域） | 品牌匹配 / 表情符号 / 话术 / ICP 全跳过 | ✅ 单批 15 | ChatGPT、DeepSeek、Kimi、通义… |
| **UGC 平台**（29 域） | 同上 | ✅ 单批 30 | B站、微博、知乎、贴吧… |
| **安全论坛**（6 域） | 同上 + 提示卡片 + 外链拦截 | ❌ | 卡饭、看雪、52pojie、T00ls… |
| **搜索引擎**（34 域） | 品牌匹配跳过 | — | Google、百度、Bing… |
| **开发者平台**（21 域） | 品牌匹配跳过 | — | GitHub、StackOverflow… |

### AI/UGC 外链核查

AI 对话和 UGC 平台中的链接是幻觉域名 / 钓鱼站 / 被入侵站的高发区。

- **五级结论**：🔴 危险 / 🟠 可疑 / 🟢 安全 / ⚪ 未知 / 🔵 检测中
- **沙箱防追踪探测**：无 Cookie、无 Referer、禁缓存、不读响应体、8 秒超时；防 SSRF（拒绝内网/回环/保留地址，DNS-over-HTTPS 预解析）
- **结论分级原则**：探测失败 ≠ 可疑，查无结果 ≠ 可疑——只有确认证据才标橙/红
- **微型徽标**：链接旁 16px 内联胶囊，不改变布局流；悬停/点击显示核查详情

### 误报治理

针对不同平台的内容特征做了精细豁免，避免"正常站被误杀"：

- AI 对话页：品牌匹配 / 表情符号 / 话术 / ICP 全跳过（AIGC/UGC 语料下文本启发式失真）
- 安全论坛：同列豁免 + 提示卡片
- 话术类正分封顶 25 分（纯文案堆分无法单独到达拦截层）
- 否定语境剔除（"非官方网站"、"并不安全"不计数）
- 备案号主体号/序号剥离比对（防 luogu.com.cn 类误报）
- 品牌关键词短词强边界（防 cline.bot 误判 LINE）
- 开发者平台 / 搜索引擎 55 域品牌豁免

### 设置面板

Chrome 扩展菜单 →「选项」打开。分区：常规 / 下载保护 / 脚本拦截 / 定位与防追踪 / 关于。所有开关持久化到 storage.local，经消息通道与后台双向同步。

## 安装

1. 下载本仓库或 `git clone`
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本目录
